## 2. 💳 How to Add a New Card - Complete Guide

### Step-by-Step Instructions:

#### **Step 1: Open Add Card Dialog**
- Go to **Cards** page (click "Cards" in sidebar)
- Click the **"+ Add Card"** button (top right)

#### **Step 2: Search or Browse Cards**
- **Search Bar**: Type card name, bank name, or card type
- **Quick Filters**: Click chips like "Credit Card", "Debit Card", etc.
- **Bank Filter**: Select a specific bank from dropdown
- **Card Type Filter**: Filter by card type

#### **Step 3: Select Your Card**
- **Option A**: Click on a card from the list above the form
- **Option B**: Select from the dropdown labeled "Card Type *"
- The selected card will show:
  - Card name
  - Bank name
  - Card type
  - Annual fee
  - Cashback rate

#### **Step 4: Enter Last 4 Digits**
- In the "Last 4 Digits of Card *" field
- Enter exactly 4 digits
- Example: `1234`
- **Security**: We only store the last 4 digits for identification

#### **Step 5: Enter Expiry Date**
- In the "Expiry Date (MM/YY) *" field
- Format: **MM/YY** (Month/Year)
- Example: `12/25` (December 2025)
- The field auto-formats as you type

#### **Step 6: Set as Primary (Optional)**
- Check the "Set as Primary Card" checkbox if this is your main card
- Only one card can be primary at a time
- Primary card is used for quick recommendations

#### **Step 7: Click "Add Card"**
- Review all information
- Click the **"Add Card"** button
- Wait for success message
- Card will appear in your cards list

### Visual Guide in Dialog:
The dialog shows a **step-by-step guide** with:
- ✅ Numbered steps (1-6)
- ✅ Clear instructions for each step
- ✅ Examples (e.g., "1234", "12/25")
- ✅ Chat button for AI help

### Troubleshooting:

**Problem**: "Please select a card type" error
- **Solution**: Make sure you selected a card from the dropdown

**Problem**: "Must be exactly 4 digits" error
- **Solution**: Enter exactly 4 numbers (no spaces, no letters)

**Problem**: "Must be in MM/YY format" error
- **Solution**: Use format like `12/25` (month/year, not day/month)

**Problem**: Card not showing in list
- **Solution**: Refresh the page or check if card was added successfully

## 3. 🔧 Smart Scraping Configuration

### Location:
- **Offers Page**: Click "Smart Scrape" button (top right)
- **Floating Button**: Bottom right corner on Offers page
- **Direct Access**: Click any "Smart Scrape" button

### Features:
- ✅ **Chat Button**: Click chat icon in dialog header for AI help
- ✅ **City Selection**: Select multiple cities to scrape
- ✅ **Scraping Speed**: Choose fast or thorough scraping
- ✅ **Bulk Scraping**: Scrape all banks at once
- ✅ **Real-time Updates**: See scraping progress

### How to Use:
1. Click "Smart Scrape" button
2. Select cities (Karachi, Lahore, Islamabad, etc.)
3. Choose scraping speed
4. Click "Start Bulk Scrape"
5. Wait for completion
6. Offers will update automatically

### Chat Button:
- Located in the **Smart Scraping Configuration** dialog header
- Click to get AI help with scraping
- Opens chatbot page for assistance
